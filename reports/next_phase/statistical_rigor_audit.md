## 1. Statistical Methodology Overview

Across completed phases, statistical validation adhered to formal testing protocols:
- **Resampling Method:** Paired bootstrap resampling with $B = 10,000$ iterations.
- **Reporting Metrics:** Difference of means ($\Delta$), two-sided empirical $p$-value, 95% bootstrap confidence intervals ($[CI_{\text{lower}}, CI_{\text{upper}}]$), and Cohen's $d$ effect sizes.
- **Significance Cutoff:** $\alpha = 0.05$ with strict two-tailed evaluation.

## 3. Critical Methodological Defect: Pseudo-Replication

### 3.1 The $N=25$ vs $N=625$ Illusion
- In Phase 10, the total run count is reported as $N=625$ (5 baselines × 5 domains × 25 runs).
- However, for any single baseline within a specific domain (e.g. Baseline B10-4 on domain $D_2$), the run count is $N=25$, generated by taking **5 documents** and running them under **5 random seeds** (`seeds: [42, 123, 456, 789, 101112]`).
- Because document difficulty dominates seed variance in document understanding tasks, the effective independent sample size is $N_{\text{eff}} \approx 5$, not $25$.
- Bootstrapping over 25 samples where every group of 5 shares the identical document underlying structure creates **clustered pseudo-replication**, artificially narrowing bootstrap confidence intervals and inflating $t$-statistics.

### 3.2 Formal Power Analysis
For a standard paired two-tailed $t$-test or bootstrap test with $\alpha = 0.05$ and desired power $1 - \beta = 0.80$:
- To detect a small effect size ($d = 0.2$), required $N \ge 199$ independent documents.
- To detect a medium effect size ($d = 0.5$), required $N \ge 34$ independent documents.
- To detect a large effect size ($d = 0.8$), required $N \ge 15$ independent documents.
- **Conclusion:** With only **5 independent documents per domain**, the benchmark is only powered to detect massive effect sizes ($d > 1.2$). It is statistically blind to subtle, realistic improvements in recovery or routing.

---

## 4. Recommendations for Next Experimental Phase
1. **Expand Independent Document Test Set:** Increase test set from 25 documents to at least **150–300 independent documents** (30–60 per domain).
2. **Cluster-Robust Bootstrapping:** Resample at the *document level* (cluster bootstrap) rather than resampling individual (document, seed) runs independently.
3. **Seed Variance Accounting:** Explicitly decompose variance into $\sigma^2_{\text{document}}$ vs $\sigma^2_{\text{seed}}$ using mixed-effects regression.
