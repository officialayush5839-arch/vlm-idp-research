# Research Risk Register — Phase 0 Risk Analysis & Contingency Planning

**Project Title**: Adaptive, Uncertainty-Aware and Evidence-Grounded Vision-Language Document Intelligence under Real-World Visual Degradation  
**Document Stage**: Phase 0 Research Protocol Freeze  
**Last Updated**: 2026-10-04  

---

## Risk Assessment Matrix (R1 – R15)

| Risk ID | Risk Description | Probability | Impact | Risk Level | Mitigation Strategy | Detection Method | Contingency Plan |
|:---:|:---|:---:|:---:|:---:|:---|:---|:---|
| **R1** | **Literature Novelty Overlap**: Concurrent publication in CVPR/ICLR/ACL proposing identical adaptive degradation routing. | Medium | High | **HIGH** | Maintain continuous literature radar using automated arXiv alerts; frame novelty on the *three-way intersection* (degradation + long-doc grounding + calibrated abstention) rather than routing alone. | Weekly literature registry audit. | Pivot experimental emphasis to the uncertainty-grounding coupling and long-document multi-page evidence retrieval. |
| **R2** | **Dataset Leakage**: Derived degraded variants accidentally appearing in test while clean document is in train. | Medium | Critical | **CRITICAL** | Enforce immutable document-level hash partitioning (`split_protocol.md`); all variants $\mathcal{V}(D_i)$ strictly inherit partition $\Pi(D_i)$. | Automated checksum and partition intersection assertion tests in CI (`test_splits.py`). | Immediate freeze and purge of tainted run outputs; re-run from immutable manifest. |
| **R3** | **Synthetic / Real Gap**: Reviewers argue synthetic corruptions (Gaussian noise/blur) fail to reflect real scanned document physics. | High | Medium | **HIGH** | Include native real-world degraded benchmarks (`FUNSD`, degraded historical receipts) alongside synthetic grid; conduct explicit ablation A12. | Correlation analysis between synthetic degradation slopes and real scan accuracy drop. | Position synthetic grid as controlled stress-testing while verifying conclusions on FUNSD. |
| **R4** | **VLM Hallucination**: Generative VLM produces fluent, plausible answer strings ungrounded in visual document pixels. | High | High | **CRITICAL** | Mandate spatial evidence grounding; reject ungrounded predictions via validation-calibrated threshold; trigger `REVIEW_REQUIRED`. | Measure Unsupported Answer Rate (UAR) and Region Recall@$K$ on every run. | Abstain from assertion when grounding IoU $< 0.50$ or fuzzy text alignment fails. |
| **R5** | **Calibration Failure**: Multi-signal uncertainty scores fail to achieve ECE $< 0.08$ on out-of-distribution degraded test sets. | Medium | High | **HIGH** | Benchmark three distinct calibrators (Platt scaling, Isotonic regression, small MLP); incorporate physical quality vectors $\mathcal{Q}$ directly into calibration feature space. | Continuous computation of ECE, Brier score, and reliability diagrams on validation splits. | Fall back to non-parametric conformal prediction intervals for rigorous empirical coverage bounds. |
| **R6** | **Evidence Grounding Failure**: VLM fails to output valid bounding box coordinates on complex multi-column layouts. | Medium | Medium | **MEDIUM** | Use native coordinate tokens in Qwen2.5-VL (`<|box_start|>`); implement OCR bounding-box alignment fallback via fuzzy text matching crop. | Automated validation of coordinate syntax and normalized interval $[0, 1000]$. | Fallback to page-level provenance with OCR bounding-box heuristic matching. |
| **R7** | **Long-Document Retrieval Failure**: Dense retrieval misses the ground-truth evidence page in 50+ page documents. | Medium | High | **HIGH** | Employ hierarchical indexing: combine page-level multimodal embeddings with dense text chunking; evaluate $k \in \{1, 3, 5, 10\}$. | Monitor Page Recall@$k$ independently of downstream QA answer accuracy. | Increase retrieval depth $k$ or implement two-stage coarse-to-fine visual reranking. |
| **R8** | **Compute & VRAM Limitations**: Local development GPU (RTX 3050 6GB VRAM) experiences Out-Of-Memory (OOM) on 7B models. | High | High | **HIGH** | Enforce 4-bit quantization (bitsandbytes / AWQ); offload embeddings to CPU; process long documents page-by-page. | Memory profiler logging peak VRAM in MB per execution. | Run full large-scale evaluation matrix in batched inference mode or leverage targeted cloud compute credits for final 5-seed publication runs. |
| **R9** | **Dataset Licensing Restrictions**: Restrictive licenses preventing commercial reuse or redistribution of test documents. | Low | Low | **LOW** | Select exclusively established, open-access academic benchmarks (DocVQA, FUNSD, SROIE, CORD, MMLongBench-Doc). | Review license files for every downloaded benchmark in Phase 1. | Exclude non-permissive datasets from publication suite; retain only fully permissible benchmarks. |
| **R10** | **Model Licensing Restrictions**: Open-source license terms restricting research publication or weight modification. | Low | Low | **LOW** | Primary model Qwen2.5-VL is Apache 2.0 / Qwen Research License; secondary InternVL2 is Apache 2.0. | Verify model cards on Hugging Face prior to integration. | Model stack consists strictly of open reproducible weights. |
| **R11** | **Reproducibility Failure**: Results differ across random seeds or execution environments due to non-deterministic CUDA ops. | Medium | High | **HIGH** | Implement `seed_everything()` locking Python, NumPy, PyTorch, and cuDNN; record full git commit, environment lockfile, and configs. | Multi-seed variance tests asserting identical results given fixed seed and environment. | Document hardware and software environment down to exact CUDA and driver versions in reproducibility appendix. |
| **R12** | **Insufficient Statistical Power**: Performance differences between Proposed and Baselines fail significance test ($p \ge 0.05$). | Low | High | **MEDIUM** | Evaluate on sufficiently large sample size ($N \ge 1,000$ QA pairs); test across 5 seeds; report bootstrap confidence intervals and effect sizes. | Run power analysis and paired bootstrap test with $B=10,000$ iterations. | Analyze failure taxonomy to identify specific degradation regimes where adaptive routing demonstrates massive effect sizes ($d > 0.8$). |
| **R13** | **Scope Explosion**: Project drifts into building end-to-end commercial software rather than focused scientific research. | Medium | High | **HIGH** | Strict adherence to `rules.md` and `goal.md`; enforce Phase 0–13 roadmaps with explicit acceptance gates; UI is demonstration-only. | Weekly audit of git commit logs against active phase tasks. | Disallow implementation of UI features, API layers, or peripheral tooling until Phase 9 experiments complete. |
| **R14** | **Weak Baseline Selection**: Reviewers critique comparisons against toy baselines rather than modern multimodal methods. | Medium | High | **HIGH** | Include modern baselines: ColPali (multimodal retrieval), Qwen2.5-VL direct, LayoutLMv3, and fixed enhancement pipelines. | Peer review of `baseline_protocol.md` against latest 2024–2025 literature. | Upgrade baselines during Phase 2 if stronger open-source document VLMs are released. |
| **R15** | **Overclaiming Novelty**: Claiming first-ever invention of individual components rather than their joint adaptive integration. | Low | High | **MEDIUM** | Frame claims precisely around the *joint degradation-routing-grounding-uncertainty framework*; acknowledge prior single-domain works. | Literature audit and cross-file consistency checks. | Rephrase claims to emphasize systematic empirical benchmarking, adaptive routing, and risk-calibrated abstention. |
