# Grounding Protocol — Spatial Provenance & Evidence Verification

**Project Title**: Adaptive, Uncertainty-Aware and Evidence-Grounded Vision-Language Document Intelligence under Real-World Visual Degradation  
**Document Stage**: Phase 0 Research Protocol Freeze  
**Last Updated**: 2026-10-04  

---

## 1. Principle of Verifiable Provenance

An answer generated by an IDP system cannot be considered reliable merely because the extracted text matches ground truth. In complex multi-page documents, true reliability requires **verifiable physical provenance**: pointing explicitly to the document page, bounding box coordinates, and visual snippet that justifies the assertion.

---

## 2. Evidence Data Schema

Every model prediction MUST produce an output conforming strictly to this JSON schema:

```json
{
  "answer": "Net revenue increased by 14.2% to $4,120M.",
  "confidence": 0.942,
  "status": "VERIFIED",
  "routing_decision": "CLEAN",
  "quality_score": 0.88,
  "evidence": [
    {
      "document_id": "doc_fin_2024_q3",
      "page": 14,
      "bbox": [124, 450, 890, 520],
      "text": "Consolidated Net Revenue was $4,120 million, representing a 14.2% increase year-over-year.",
      "score": 0.961
    }
  ],
  "reasoning_summary": "Extracted from Consolidated Financial Highlights table on page 14."
}
```

## 3. Coordinate System & Normalization

1. **Normalized Coordinate Space**:
   All bounding box coordinates are normalized to the integer interval $[0, 1000]$:
   $$\bar{x}_1 = \left\lfloor \frac{x_1}{W} \times 1000 \right\rfloor, \quad \bar{y}_1 = \left\lfloor \frac{y_1}{H} \times 1000 \right\rfloor$$
   $$\bar{x}_2 = \left\lfloor \frac{x_2}{W} \times 1000 \right\rfloor, \quad \bar{y}_2 = \left\lfloor \frac{y_2}{H} \times 1000 \right\rfloor$$
   Where $W, H$ are the native pixel width and height of the original page image.
2. **Format Convention**:
   Coordinates are strictly formatted as $[x_{\text{min}}, y_{\text{min}}, x_{\text{max}}, y_{\text{max}}]$ where $0 \le x_{\text{min}} < x_{\text{max}} \le 1000$ and $0 \le y_{\text{min}} < y_{\text{max}} \le 1000$.

---

## 4. Grounding Evaluation Protocol

1. **Successful Grounding Criterion**:
   A predicted bounding box $B_{\text{pred}}$ on predicted page $p_{\text{pred}}$ is deemed **valid** if:
   $$p_{\text{pred}} \equiv p_{\text{gt}} \quad \wedge \quad \text{IoU}(B_{\text{pred}}, B_{\text{gt}}) \ge 0.50$$
2. **Textual Verification**:
   The text extracted from the document crop defined by $B_{\text{pred}}$ must contain or fuzzy-match ($\text{Levenshtein} \ge 0.70$) the generated answer tokens.
3. **Automatic Fallback to Review**:
   If the VLM produces an answer string but fails to produce valid bounding boxes ($\text{IoU} < 0.50$ or coordinates outside image boundaries):
   $$\text{status} \longleftarrow \text{"REVIEW\_REQUIRED"}$$
   The system prohibits marking an answer as `VERIFIED` without verified spatial grounding.
