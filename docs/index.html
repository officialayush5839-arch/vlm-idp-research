Stage I · Quality Assessment & Tri-Pathway Routing

Adaptive Processing Under Visual Stress

Visual degradation (motion blur, low contrast, sensor noise, skew) severely impairs standard VLM autoregression. Our framework estimates a multi-signal quality vector and dynamically routes documents through three dedicated pathways:

CLEAN ROUTE Direct VLM

High-fidelity scans bypass heavy preprocessing, routing directly to the vision-language backbone for maximal extraction efficiency and sub-second response times.

MODERATE ROUTE Enhancement + VLM

Mild degradation triggers adaptive Wiener deconvolution, geometric deskew, and contrast normalization prior to multimodal encoding, recovering compromised visual features.

SEVERE ROUTE OCR-Assisted Hybrid

Catastrophic visual degradation activates OCR character fallbacks (PaddleOCR + Tesseract), injecting structured textual coordinates into prompt context to prevent VLM hallucination.

ABSTENTION GATE Human Escalation

When multi-signal uncertainty crosses the learned calibration boundary, the system safely abstains with machine-verifiable citations, routing ambiguous cases for human review.
